# 🚘 Auto Estética App

A native Android app for a car detailing ("auto estética") shop, connecting clients and the shop owner in one place.

---

## 🚀 Planned Features

For clients: schedule appointments with the shop, leave reviews about the services received, browse photos of previously executed services, and quickly access the shop's contact phone number.

For the shop owner: a dashboard to manage product inventory and generate sales reports.

---

## 🛠️ Tech Stack

Native Android (Kotlin), with the backend/data layer (Firebase or a REST API) to be defined as development starts.

---

## 📌 Status

This project is in the planning/early development stage. Progress and code will be tracked in this folder as the app is built.
