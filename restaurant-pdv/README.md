# 🍽️ Restaurant PDV

A point-of-sale (PDV) system built for small and medium-sized restaurants, designed to run on a local server.

---

## 🚀 Planned Features

Order management for tables and counter sales, menu and pricing control, and daily sales reporting — built with a focus on running fully on a local network, without depending on constant internet access.

---

## 🛠️ Tech Stack

Native backend and database stack to be defined as development starts.

---

## 📌 Status

This project is in active development. Progress and code will be tracked in this folder as the app is built.
